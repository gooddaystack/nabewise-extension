# Privacy

The live policy is [https://nabewise.com/privacy](https://nabewise.com/privacy).

NabeWise 1.2 does not send listing addresses to a server. The neighborhood index is bundled. A city filter stays in `chrome.storage.local` on this browser. Listing pages are read in-page so the card can name an official unit. Clicks go to `https://nabewise.com/{city}/{slug}`.
